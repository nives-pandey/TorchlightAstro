# Reference material

Not part of the Torchlight application. Nothing here is imported by `apps/` or
`packages/`, and none of it ships.

## `legacy-algorithms/`

Source files from an earlier prototype, kept only so their approach can be read
while the current engine is written. They are **not** authored as part of this
project and carry no copyright header for that reason.

Treat them as notes, not as code. Several contain calculations that were found
to be wrong — the reason the engine was rebuilt from primary sources rather than
ported.

## `product-vision/`

Original specification and design documents describing the product intent.
