Torchlight Design System Conformance Test
Objective: To create a robust system that ensures 100% of the codebase adheres to the rules defined in the Torchlight Global Design System. This prevents "design drift" and guarantees a cohesive, premium user experience.

Part 1: The Automated Audit Script (The "Code Cop")
This is a simple but powerful script that acts as your automated tester. It scans the entire frontend codebase for "illegal" colors or fonts that violate the design system. It should be run before any new code is merged.

Why it works: This script automates the tedious task of checking for hardcoded values. It will instantly flag any developer who, out of habit or mistake, uses an old purple color instead of the correct CSS variable.

Instructions:

Create a new file in the root directory of your project named audit-design-system.mjs.

Copy and paste the code below into that file.

Run the script from your terminal using the command: node audit-design-system.mjs.

// audit-design-system.mjs
import fs from 'fs';
import path from 'path';

// --- Configuration ---
// Add any other forbidden color patterns here.
const FORBIDDEN_PATTERNS = [
    // Purples & Blues (Hex, HSL, RGB)
    /#[a-fA-F0-9]{0,2}(5a|6a|7a|8a|9a|aa|ab|ac|ad|ae|af|b|c|d|e|f)[0-9a-fA-F]{0,2}[a-fA-F0-9]{2}/i, // Catches a wide range of purples/blues
    /hsl\(\s*(2[4-9][0-9]|3[0-5][0-9])\s*,/i, // HSL hues from 240-359 (purples/pinks)
    /hsl\(\s*(1[8-9][0-9]|2[0-3][0-9])\s*,/i, // HSL hues from 181-239 (cyans/blues)
    
    // Forbidden Font Families
    /'(Cinzel|Philosopher|Celtic|Gothic)'/i,
];

const ALLOWED_FILES = ['.tsx', '.ts', '.css'];
const DIRECTORY_TO_SCAN = './client/src'; // Adjust if your source code is elsewhere

let errorCount = 0;

function auditFile(filePath) {
    const content = fs.readFileSync(filePath, 'utf8');
    const lines = content.split('\n');

    lines.forEach((line, index) => {
        FORBIDDEN_PATTERNS.forEach(pattern => {
            if (pattern.test(line)) {
                console.error(`❌ Design System Violation Found!
   - File: ${filePath}
   - Line: ${index + 1}
   - Issue: Forbidden color or font detected.
   - Code: "${line.trim()}"\n`);
                errorCount++;
            }
        });
    });
}

function scanDirectory(dir) {
    const files = fs.readdirSync(dir);
    files.forEach(file => {
        const fullPath = path.join(dir, file);
        const stat = fs.statSync(fullPath);
        if (stat.isDirectory()) {
            scanDirectory(fullPath);
        } else if (ALLOWED_FILES.includes(path.extname(fullPath))) {
            auditFile(fullPath);
        }
    });
}

console.log('--- Starting Torchlight Design System Audit ---');
scanDirectory(DIRECTORY_TO_SCAN);
console.log('--- Audit Complete ---');

if (errorCount > 0) {
    console.error(`\n🚨 Audit Failed: Found ${errorCount} design system violation(s). Please fix the issues listed above.`);
    process.exit(1); // Exit with an error code to fail CI/CD pipelines
} else {
    console.log('\n✅ Audit Passed: No design system violations found. Great work!');
}

Part 2: The Manual Review Checklist (The "Brand Guardian")
This checklist should be added to your team's pull request (PR) template. Before merging any UI-related code, the author or a reviewer must manually check these boxes.

Why it works: The automated script catches technical errors, but this checklist enforces the philosophy of the design. It forces a moment of conscious reflection to ensure the new component "feels" like it belongs in the sanctuary.

Pull Request Checklist:

### Design System Conformance Checklist

_Before merging, please confirm the following:_

-   **[ ] Color Palette Adherence:** All colors used in this component are from the **Global Color Palette** (`#36312E`, `#D4B35B`, `#208B8B`, `#F5F5DC`, `#B0A9A4`). No hardcoded or "rogue" colors have been introduced.
-   **[ ] Interactive Color Rule:** All interactive elements (buttons, links, active states) exclusively use the **`Polished Gold`** (`#D4B35B`) accent color.
-   **[ ] Typography Adherence:** All fonts, sizes, and weights conform to the **Global Typography System** (`Montserrat` for UI, `Lora` for body).
-   **[ ] Structure & Width:** The component respects the **Global Structure** rules (single-column, max-width of `896px` on desktop, consistent card styling).
-   **[ ] "Sanctuary" Feel:** Does this component feel calm, premium, and serene? Does it align with the "Illuminated Wellness Sanctuary" philosophy? (Yes/No)

By combining the automated precision of the audit script with the mindful, human-centric review of the checklist, you create a powerful system that ensures your design vision is perfectly translated into the final product, every single time.
