Torchlight Troubleshooting & Implementation Guide for Replit
This guide provides the exact code and instructions to fix the data integrity issues and build the new cross-system and lifestyle recommendation engines for your Torchlight application.

Part 1: Fix Human Design Data Integrity (CRITICAL)
This two-step process will immediately stop the flow of fabricated data and then replace it with an authentic, free-of-cost solution.

Step 1.1: The Emergency Brake (Frontend Feature Flag)
This will instantly hide the feature from your users.

Navigate to your frontend code in Replit, likely in a file such as client/src/pages/Personal.tsx or wherever the Human Design chart is displayed.

Wrap the Human Design component in a simple conditional check.

// Example in a React component

// ... other imports

      )}

      {/* ... other components */}
    </div>
  );

Action: Copy the showHumanDesign constant and the {showHumanDesign && ...} wrapper around your existing Human Design component. When you deploy, Replit's NODE_ENV will be 'production', and the feature will be hidden.

Step 1.2: The Permanent Fix (Backend Integration)
This creates a new service on your backend to handle authentic calculations.

Install the library: Open the Shell tab in Replit and run this command:

npm install js-humandesign

Create a new file: In your server/ directory, create a new file named human-design-service.ts.

Copy and paste this code into server/human-design-service.ts:

// server/human-design-service.ts
import { HumanDesign } from 'js-humandesign';

interface BirthData {
  birthDate: string; // "YYYY-MM-DD"
  birthTime: string; // "HH:MM"
  timezone: string;  // e.g., "America/New_York"
}

export const getAuthenticHumanDesignChart = (data: BirthData) => {
  try {
    // The library expects a Date object. We construct it carefully.
    const dateTimeString = `${data.birthDate}T${data.birthTime}:00`;

    // Note: This creates a date based on the server's local time. For production,
    // you would use a library like 'date-fns-tz' to handle timezones correctly.
    const birthDateTime = new Date(dateTimeString);

    if (isNaN(birthDateTime.getTime())) {
      throw new Error('Invalid date/time format');
    }

    const chart = new HumanDesign({
      time: birthDateTime,
      // Note: The js-humandesign library doesn't use location for basic chart calculation
      // but you might need it for more advanced features if the library supports it.
    });

    // Return the core, authentic data
    return {
      success: true,
      data: {
        type: chart.type,
        strategy: chart.strategy,
        authority: chart.authority,
        profile: chart.profile.name,
        definition: chart.definition.name,
      },
    };
  } catch (error) {
    console.error("Error generating Human Design chart:", error);
    return { success: false, error: "Failed to generate authentic Human Design chart." };
  }
};

Update your API route (e.g., in server/routes.ts) to call this new service instead of the fake calculation.

interface SystemAnalysis {
  system: string;
  analysis: object; // The JSON analysis for a single system
}

export const synthesizeCompatibility = async (
  person1Analyses: SystemAnalysis[],
  person2Analyses: SystemAnalysis[],
  userQuestion: string
): Promise<{ success: boolean; synthesizedInsight?: string; error?: string }> => {

  const masterPrompt = `
    **Role:** You are a master astrologer with unparalleled expertise in synthesizing disparate mystical systems into a single, coherent narrative.

    **Context:** A user is asking about the compatibility between two individuals. I have provided the separate astrological analyses from different systems. Your task is to integrate these into a unified, insightful, and easy-to-understand answer.

    **[Persona 1: Chart Analyses]**
    ${person1Analyses.map(a => `// ${a.system} Analysis:\n${JSON.stringify(a.analysis, null, 2)}`).join('\n\n')}

    **[Persona 2: Chart Analyses]**
    ${person2Analyses.map(a => `// ${a.system} Analysis:\n${JSON.stringify(a.analysis, null, 2)}`).join('\n\n')}

    **[User's Question]**
    "${userQuestion}"

    **Your Task:**
    1.  **Identify Core Themes:** Analyze both sets of data to find the major points of harmony and the primary points of tension.
    2.  **Synthesize, Do Not List:** Weave the findings together into a narrative. For example, instead of "Western says you are compatible and Vedic says you have challenges," say "While your core personalities align beautifully, as shown in your Western charts, your Vedic analysis points to some karmic challenges you may need to navigate together."
    3.  **Answer Directly:** Directly address the user's question with the synthesized data.
    4.  **Provide Actionable Insight:** Conclude with a single, actionable piece of advice based on the unified analysis.

    **Output Format:** A warm, insightful, paragraph-based response.
  `;

  try {
    const synthesizedInsight = await callAI(masterPrompt);
    return { success: true, synthesizedInsight };
  } catch (error) {
    console.error("AI Synthesis failed:", error);
    return { success: false, error: "Failed to synthesize compatibility report." };
  }
};

  userChartData: object, // The user's full multi-system chart

    **Role:** You are a master lifestyle astrologer specializing in ${recommendationType}.

    **[User Astrological Profile]**
    ${JSON.stringify(userChartData, null, 2)}

    **[${recommendationType.charAt(0).toUpperCase() + recommendationType.slice(1)} Knowledge Base]**
    ${JSON.stringify(knowledge, null, 2)}

    **User's Current Goal:** "${userGoal}"

    **Your Task:**
    1.  Analyze the user's chart to identify the key astrological elements related to their goal.
    2.  Based on the planetary strengths and weaknesses in their chart, select the single most effective item from the knowledge base to support their goal.
    3.  Provide a clear recommendation and a one-sentence rationale directly linking it to their specific astrological placements.
  `;

  try {
    const recommendation = await callAI(prompt);
    return { success: true, recommendation };
  } catch (error) {
    console.error(`Lifestyle recommendation for ${recommendationType} failed:`, error);
    return { success: false, error: "Failed to generate lifestyle recommendation." };
  }
};
